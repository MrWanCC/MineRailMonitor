# 打包与验收工具

```text
scripts/
├─ 打包工具/       一键打包入口、桌面包构建和校验脚本
├─ 验收工具/       Loopback 验收脚本和场景清单
└─ 打包结果/
   ├─ 正式包/      正式部署 ZIP 和解压目录
   ├─ 测试包/      测试部署 ZIP 和解压目录
   └─ 暂存/        每次打包的临时 staging
```

运行 `打包工具\一键打包正式.cmd` 后，到 `打包结果\正式包` 找正式 ZIP；运行 `打包工具\一键打包测试.cmd` 后，到 `打包结果\测试包` 找测试 ZIP。

`打包结果` 已加入 Git 忽略规则，生成的 ZIP 和解压文件不会提交到源码仓库。
