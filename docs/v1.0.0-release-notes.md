# MineRailMonitor v1.0.0 Release Notes

## 版本定位

MineRailMonitor v1.0.0 为当前内部验收后的正式首版源码整理版本。

## 主要能力

- RFID 40 字节通信协议：支持 RFID 分站轮询、请求/响应解析和 CRC 校验。
- External Alarm 12 字节状态发送：按 RFID 分站状态发送 `01` 正常、`02` 识别中、`03` 脱节报警。
- External Alarm 清除接收：独立 UDP 接收清除帧，校验后进入现有 `Clear → WaitForEmpty → Idle` 恢复流程。
- 560、620 站场通信及报警目标配置独立隔离。
- Simulator 闭环验证：正常、识别、报警、外部清除和恢复场景均已覆盖。
- 旧 `AlarmForward` 类型、配置模型和 API 保留兼容，但运行链路不再发送原始 40 字节报警报文。

## 已知现场风险

- External Alarm CRC 算法及高低字节顺序仍需与现场最终协议表确认。
- 需现场确认 560、620 的 RFID 监听 IP/端口、External Alarm 目标 IP/端口和清除监听端口。
- 需确认 Windows 防火墙及现场网络允许对应 UDP 入站和出站通信。
- 需确认 External Alarm 地址 Byte2 与对应 RFID 分站地址一致。
- 外部 UDP 发送失败不会改变 RFID 通信健康状态，但仍需通过日志监控目标不可达问题。
